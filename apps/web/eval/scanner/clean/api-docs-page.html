Parcelly REST API

The Parcelly API lets you create shipping labels, track parcels across 40+ carriers and receive delivery updates in real time. All requests are made to the base URL below and return JSON.

https://api.parcelly.dev/v2

Authentication

Authenticate every request with your secret API key in the Authorization header. You can create and rotate keys from Dashboard → Developers → API keys. Test keys start with pk_test_; live keys with pk_live_.

curl https://api.parcelly.dev/v2/shipments \
  -H "Authorization: Bearer <your_api_key>"

Keep your secret keys server-side. Never embed them in a mobile app or browser bundle.

Errors

StatusMeaning
400The request body failed validation. See error.fields.
401Missing or invalid API key.
404The resource doesn't exist or belongs to another account.
429Rate limited. Retry after the number of seconds in Retry-After.
{
  "error": {
    "type": "invalid_request",
    "message": "to_address.postal_code is required",
    "fields": ["to_address.postal_code"]
  }
}

Create a shipment

POST/v2/shipments

Creates a shipment and purchases a label from the cheapest carrier matching your service level.

ParameterTypeDescription
from_addressobjectSender address. Required.
to_addressobjectRecipient address. Required.
parcelobjectWeight in grams and dimensions in cm.
service_levelstringeconomy, standard or express. Defaults to standard.
curl -X POST https://api.parcelly.dev/v2/shipments \
  -H "Authorization: Bearer <your_api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "from_address": { "name": "Hollow Oak Ceramics", "line1": "12 Mill Lane", "city": "Bristol", "postal_code": "BS1 4DJ", "country": "GB" },
    "to_address":   { "name": "Jonas Weber", "line1": "Kastanienallee 7", "city": "Berlin", "postal_code": "10435", "country": "DE" },
    "parcel": { "weight_g": 1200, "length_cm": 30, "width_cm": 20, "height_cm": 12 },
    "service_level": "standard"
  }'

Response

  "tracking_number": "JD014600006281234567",

}

Retrieve a shipment

GET/v2/shipments/{id}
curl https://api.parcelly.dev/v2/shipments/shp_8Kq2vXr41 \
  -H "Authorization: Bearer <your_api_key>"

List shipments

GET/v2/shipments?limit=20&status=in_transit

Returns a cursor-paginated list, newest first. Pass starting_after with the last ID to fetch the next page.

Cancel a shipment

DELETE/v2/shipments/{id}

Voids the label and refunds the rate if the carrier hasn't scanned the parcel yet.

Webhooks

Register an HTTPS endpoint and we'll POST a shipment.updated event whenever tracking changes. Each request carries a Parcelly-Signature header — verify it with your webhook signing secret before trusting the payload.

{
  "type": "shipment.updated",
  "data": { "id": "shp_8Kq2vXr41", "status": "delivered" }
}

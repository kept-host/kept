    Nap idle tabs

    Tabs you haven't touched in 30 minutes go to sleep and free up memory. Click to wake them instantly.

    🧶

    Project groups

    Save a set of tabs as a "yarn ball" and reopen the whole project tomorrow.

    ⌨️

    Ctrl + Shift + K

    Fuzzy-search every open tab across every window, then jump straight to it.

    Your tabs are none of my business.

    Tabby Cat runs entirely on your device. It asks only for the tabs and storage permissions, has no analytics, and makes no network requests. The code is open source on GitHub so you can check.

My notes aren't syncing

  1. Check status.brightsidenotes.app for any ongoing incident.
  2. Make sure you're signed in to the same Brightside account on each device (Settings → Account).
  3. Pull down on the notes list to force a sync. The small cloud icon turns solid when it's done.
  4. Update to the latest version — sync fixes ship often. Current version is 4.8.2.
  5. Still stuck? Go to Settings → Help → Send diagnostics. It sends an anonymous sync log (never note contents) and gives you a reference code to include in your email.
